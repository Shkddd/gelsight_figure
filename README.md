# GelSight PPO Grasp Simulation

基于 PPO 的灵巧手圆柱抓取仿真，输入为 **GelSight 指尖触觉传感器**的 2D 形变矩阵，输出各关节电机转矩。

## 项目结构

```
├── train_grasp_ppo.py      # PPO 训练脚本（CNN 触觉编码器 + Actor-Critic + GAE）
├── visualize_grasp.py       # 实时可视化：俯视图、GelSight 热图、力/偏移时序
└── README.md
```

## 快速开始

```bash
# 安装依赖
pip install torch numpy matplotlib

# 随机策略基准测试
python3 train_grasp_ppo.py --mode bench

# 训练（60k 步，约 5 分钟）
python3 train_grasp_ppo.py --mode train --max-steps 60000

# 可视化训练好的策略
python3 visualize_grasp.py --checkpoint grasp_ppo_best.pt --max-steps 300
```

## 环境

| 参数 | 值 |
|------|-----|
| 手指数 | 3（拇指/食指/中指） |
| 每指关节 | 3 |
| 触觉传感器 | GelSight 64×64 深度图（模拟） |
| 抓取目标 | 圆柱体，半径 0.02m，质量 0.1kg |
| 动作空间 | 9 维转矩 [-1, 1]（Tanh 限制） |
| 物理仿真 | 刚度接触 + 库仑摩擦 + 二阶关节动力学 |

## 奖励设计

| 分量 | 权重 | 说明 |
|------|------|------|
| 存活奖励 | +1/步 | 不掉落即奖励 |
| 力惩罚 | -0.02 × 误差² | 鼓励接触力接近 2.0N |
| 均匀性惩罚 | -10 × 标准差 | 三指力尽量均匀 |
| 能耗惩罚 | -0.001 × Στ² | 最小化力矩 |
| 急动惩罚 | -0.0001 × Δτ² | 平滑动作 |

## 触觉力模型

手指闭合度（grip）→ 法向力映射：

| grip | 每指法向力 | 总力 | 效果 |
|------|-----------|------|------|
| 0.0 | 0.3 N | 0.9 N | < mg 滑落 |
| 0.3 | ~1.0 N | 3.0 N | 刚好抓住 |
| 0.5 | ~1.9 N | 5.7 N | 牢固抓紧 |
| 1.0 | ~4.5 N | 13.5 N | 强力抓紧 |

## 可视化

运行 `visualize_grasp.py` 会弹出 4 面板窗口：

1. **俯视图** — 手指位置（随关节值移动）+ 力箭头
2. **GelSight 热图** — 每指 64×64 接触形变
3. **力时序** — 三指法向力随时间变化
4. **z 偏移** — 圆柱下落高度

## 训练效果

约 9000 步后策略学会稳定抓握（100% 成功率维持 200 步以上不掉落）。
